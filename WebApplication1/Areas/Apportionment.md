Apportionment

Use this module to manage apportionment between members of a micro-credit group.

To access this sub module click on: Micro-credit Module -> Navigate -> Operations ->Apportionment

Apportionment

The following screen will open.

1\. Full Account Number - Click on the lookup icon to open 'Customer Account Lookup' dialogue box. Select the microcredit group you want to apportion.

The rest of the account details will be loaded automatically.

2\. On the apportionment pane

i) Full Account Name - Click on the lookup icon to open 'Customer Account Lookup' dialogue box. Select the customer who belongs to the microcredit group selected above. Their details will be loaded automatically.

ii) Principal - Enter the principal amount to be apportioned

iii) Interest - Enter the interest amount to be apportioned

3\. Click on the add button to add.

Do these for the rest of the group members to be apportioned.

4\. Import - Use the import option to import an excel file for the group members apportionment.

To use this import option, select the microcredit group first (Refer to step 1)

Click on the import button then show advance to see the excel format.

Click on the check box if you want the savings balance to be included on recovery.

Click on check box if you want to invoke electronic funds transfer.
