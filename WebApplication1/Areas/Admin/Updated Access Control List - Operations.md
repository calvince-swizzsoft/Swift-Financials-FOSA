Operations

To access this module click on Administration Module - > Operations - > Access Control Lists - > Operations

This module is for issuing permission to various institutional operations. The roles assigned to these tasks requires Authorization for specific functions in Vanguard Financials. Some of these roles are shown in the screen shots below;

Operations fig.1

- Assign a Role by selecting a System Permission Type from the drop down list as shown in the figure above then tag the Roles to assign the permission.
- Click on Update once you have checked the roles for each of the Permission Type selected.

Note: You can assign multiple roles to a Permission Type.
