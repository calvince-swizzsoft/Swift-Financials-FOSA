Cash Withdrawal Request

Use this module to create, authorize or reject cash withdrawal requests.

To access this module Click on Front-Office Module - > Navigate - > Operations - > Treasury -> Cash Withdrawal Request

Creating a cash withdrawal request

1\. To create a cash withdrawal request, click on the create button.

The following screen will open.

Cash Withdrawal Request

Cash Withdrawal Request fig 1

2\. Select the Customers "Savings Account #" by clicking on the account # lookup icon . The details of that account will be loaded.

3\. Enter the Amount that the customer wants to place a notice for.

4\. Enter the remarks accordingly.

5\. Click on the create button to save changes.

Authorizing a cash withdrawal request

1\. To identify a withdrawal request to authorize use date range or the search field.

1. Using date - select the date range or specific date when the withdrawal request was placed by selecting a start date and an end date.
2. Using the search field - use the search field to enter the details of the withdrawal request, i.e. by typing a customers account number or name.

A withdrawal request has the authorization status as pending, rejected or authorized/paid.
