Inventory Categories

The inventory category module is used for creating inventory categories for individual inventory items , for example pens and rulers can be

categorized as stationary. Categorizing inventory makes book keeping easier. Here you can create categories which you will use to group objects in your inventory

catalogue.

To access this sub module click on: Control Module -> Navigate -> Setup -> Inventory Categories
