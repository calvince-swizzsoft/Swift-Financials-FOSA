Asset Types

The asset types module is used for creating various categories of assets

Each type of asset has different life spans and depreciation patterns you can create asset types based on depreciation, useful life span.

You will later use these asset types to categories your organizations assets.

This allows you to give proper evaluation and categorization of assets.

To access this sub module click on: Control Module -> Navigate -> Setup -> Asset Types
