Conditional Lending

This is where you set the type of loan that specific set group of people can be able to get.

Example ,staff loan,only staff members can be able to get that type of loan.

To access this module click on Registry Module - > Navigate - > Operations - > Customers - > Conditional lending

When you click on Conditional lending the following screen opens:

Conditional Lendings

If you have conditional lendings set they will be displayed in the field shown in red below.you can also use the search field to search for a specific type of set conditional lending

Conditional Lendings

How to Create Conditional Lendings

1\. Click on the create button to create conditional lendings.The following screen opens when you click on the Create button:

Conditional Lendings

2.Enter The name of The type conditional lending that you want to set

3.Select the loan product by clicking on the look up button .The following screen opens after clicking on the look up button:

Conditional Lendings

4.select the loan product you want.you can also use the search field to search for a specific loan product.increase the number of ITEMS PER PAGE

to view more loan products

After you have selected the loan product you want data populates in most of the remaining fields

// Remember to select between FOSA and BOSA loan products from the menu circled in red when searching for loan products

5.Click on the customer look up button to search for the customers you want to add to that conditional lending list.you can search for a

customer by using account number,first name,last name,identity card number etc as shown below:

Conditional Lendings

6.Enter the account number and the remarks appropriately.

7.click on the Add button to add more customers to that list.

8.Repeat steps 1 to 7 to add more customers then click create to complete the process.

You will receive a pop up message indicating that the operation was completed successfully.
