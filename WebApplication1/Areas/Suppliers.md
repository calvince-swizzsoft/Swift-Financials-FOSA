To access this sub module click on: Control Module -> Navigate -> Setup -> Suppliers

# **Fill in the form with data in the relevant fields.**

Name - Enter the name of the supplier, it may be an individual or a company.

Address line 1 & 2 - Type in the address of the supplier, if there are 2 addresses fill in both if not fill in one.

Street - Type in the name of the street the supplier is located on.

Postal Code - Type in the postal code of the location the supplier is located at.

Land-Line - Type in the telephone number of the supplier.

Mobile-Line- Type in the Mobile Phone Number of the supplier in this space.

E-mail - Type in the full e-mail address of the supplier here, if there are more than one e-mail separate each e-mail by a comma

G/L Account - Click on the lookup icon to open a "G/L Account Lookup", select the account.

Once you're done filling in the required details click on create to complete creating a supplier.
