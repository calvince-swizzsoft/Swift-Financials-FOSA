Salary Groups

This module creates Job Groups that will be used to pay the Employees in various categories (groups)

To access this module click on Human Resource Module->Navigate->Operations->Salary->Salary Groups

The following screen will open :

Salary Groups

Salary Group fig.1

Creating a new salary group

1\. Click on the create button and the following screen will open.

Salary Groups

Salary Group fig.2

2\. Enter the Name of the Group for example, Job Group A, or Job Group B or Job Group C etc

Enter the salary group details:

3\. Salary Head - Click on the salary head look up icon to select a salary head from the existing list of salary heads.

4\. Select the value type whether fixed amount or percentage.

5\. Enter the value of the salary head.

6.Enter the Minimum Value to be associated with the salary group being created.

7\. Select the Rounding type from the drop down list of options :

Salary Groups

Salary Group fig.3

7\. Click on the add button every time you capture a salary group entry. In case there is an erroneous entry, select on the salary group entry and click on the remove button.Re-enter the correct details and click on the add button.

8\. Click on the create button to save changes.

A pop up message confirming that the salary group was created successfully will appear.

Note: You are to repeat the above procedure for all salary groups.

How to edit a salary Group

1\. Identify the salary group you want to edit.

2\. Click on the edit icon twice to be able to edit a salary group. Refer to the figure below ;

3\. Edit the salary group appropriately.

4\. Click on the create button to save changes.
