Catalogue

The catalogue sub-module is used for registering/entering Assets into the systems. Each asset you add has a detailed overview of the assets information.

To access this sub module click on: Control Module -> Navigate -> Operations -> Assets->Catalogue

- 1. Setting up of catalogue

# **The following screen will open when you click on catalogue.**

# **Catalogue Figure1.**

# **Click on the green create icon located on the bottom right of the screen. The create icon looks like this .**

#

# **The following screen will open.**

# **Catalogue Figure2.**

#

# **Fill in the form as follows;**

# **Name- Enter the name of the asset here.**

# **Remarks-Enter a remark regarding the asset here, for example if the asset has a warranty enter this information here.**

# **Asset Type- Select the type of asset you are adding. Click on the lookup icon , to open a list of asset type options.**

# **Select the asset type by clicking on the desired type.See the figure below.**

# **Catalogue Figure3.**

# **Supplier-Click on the lookup icon to open a menu of suppliers, select the supplier of the asset from the list by clicking on the correct supplier.**

# **Department- Click on the lookup icon to open a list of departments in your organization**

# **select where the asset belongs in terms of departments.**

# **Picture- Click on the look up icon to open a browser of your computer files, select the file that contains the photo of the asset you're adding.**

# **Once you select the file from your computer click OK and the picture will be loaded into the system.**

# **G/L Account- Select the appropriate G/L account for the asset you're creating by clicking on the look up icon next to G/L account.**

# **select a G/L account from the list of accounts.**

# **Serial Number- Type in the serial number of the asset, the serial number is usually found on asset.**

# **Manufacturer- Enter the name of the manufacturer of the asset.**

# **Model- Enter the model number of the asset if applicable.**

# **Tag Number- Enter the tag number of the asset.**

# **Location- Enter the current location of the asset.**

# **Purchase Price- Enter the price the asset was purchased for by your organization.**

# **Residual Value- Enter the residual value of the asset.**

# **Once you have filled in all the details click on the green create button located at the bottom right of the screen.**

# **A pop up box informing you that changes have been saved onto the system will pop up if you followed the instructions correctly.**

# **Congratulations you have completed creating your first asset on Vanguard.**
