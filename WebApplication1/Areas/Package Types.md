Package Types

Use the package type module to create different packages your organization will be using for transportation of goods, storing of goods.

To access this sub module click on: Control Module -> Navigate -> Setup ->Package Types

1.Setting up of Package Types

To setup a package type and its details, follow the illustration and instructions below;

The following screen will open when you click on the package types.

Name - Enter the name of the package type.

Remarks - Type in a brief remark regarding the package type, giving more insight to the package type.

Once you've completed adding the information click on the green create button located at the bottom right of the screen.

A pop up box notifying you that you have successfully saved changes to the system will pop up if you followed the instructions correctly.

You may want to edit a package type later on without deleting an existing one.

To edit a package type do the following.

Open the package type sub module and click on the edit icon next to the package type you want edited. The edit icon looks like this.
