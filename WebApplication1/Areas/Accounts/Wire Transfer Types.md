Wire Transfer Types.

Use this sub-module to set up the wire transfer types products.

To access this window, click :Accounts Module - > Setup - > Wire Transfer Types.

The following screen will be opened:

Wire Transfer Types fig1.

To view a list of the Wire Transfer Types.

Click on the REFRESH Button to reload the data onto the screen.

Wire Transfer Types fig2

.

To Create a Wire Transfer Type.

Click on the CREATE Button. The following screen will be opened:

Wire Transfer Types fig 2

On the above screen:

Name - Enter the name of wired transfer type being created.

G/L Account - Click on the look up icon to open the following screen :

Wire Transfer Types fig 3.

Select an appropriate account to be mapped onto the wire transfer type being created.

Transaction Ownership - Select the appropriate transaction ownership to be enforced on the wire transfer type being created.

Applicable Charges - Select the appropriate applicable charges to be enforced on the wire transfer type being created.

NOTE: If the wire transfer type is locked check box is selected, as on this figure, this means that the transfer is not available for use.

When done filling in all the data as elaborated above, click on the CREATE Button.

On successful completion you will get a pop up message confirming that the operation was successful
