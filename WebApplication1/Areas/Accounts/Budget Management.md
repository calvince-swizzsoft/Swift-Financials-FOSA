Budget

Use this sub-module to set up the bank Budget.

To access this window, click :Accounts Module - > Operations- > Budget Management - >Periods.

The following screen will be opened:

Budget Entries fig1.

How to view a budget entry

1\. To view a Budget, identify and click on that particular Budget.

2\. The entries of that particular budget you have clicked will be displayed on the "Budget Entries" pane at the bottom as illustrated in the figure below:

Budget Entries fig 2.

How to Create a Budget

1\. Click on the CREATE Button, to open the following screen:

Budget Entries fig 3.

2\. On this Create screen, fill in all the required data in all fields:

Name - Enter the name (or description) of the Budget to be created

Total Value - Enter the total value / figure that's being budgeted

Posting Period - Click on the lookup icon to select the appropriate Posting Period for that Budget .

Branch - Click on the lookup icon to select the appropriate Branch for that Budget .

6\. When done click on the CREATE Button to complete this task.

On successful completion you will get a pop up message confirming that the operation was successful.

How to Edit a Budget

1\. First Identify the Budget to be edited.

2\. On that Budget that's been identified, at the far left, double click on the edit icon to open the following screen: (in this case we are editing Budget 2018)

Budget Entries fig 4.

2\. On this Edit screen, modify all the required data in the relevant fields:

Name - Modify the name (or description) of the Budget

Total Value - modify /enter a new figure for the total value that's being budgeted for

Posting Period - Click on the lookup icon to change or select a new Posting Period for that Budget .

3.Next Step is to modify the details of that particular Budget Entries

i) To Add more Budget Entries

G/L Account - Click on the lookup icon to change/ select a new G/L Account for that Budget .

Amount - Enter the new amount that's to be spent on that particular Budget Entry for that posting period

Reference - Enter/ modify the reference for the budget period.

4\. Click on the "ADD" Button to add that entry into the system

ii) To Remove a Budget Entry

5\. Select and click on the Budget Entry to be removed.

6\. Click on the REMOVE Button.

REMEMBER: Once you remove a budget entry and the Total Amount figure IS NOT EQUAL to the total amount of the budget entries, therefore the system will NOT update.

iii) To Add new entries after removing some

7\. Repeat steps 3 & 4 Enter more Budget Entries for that posting period.

NOTE: The Entries AMOUNT entered MUST total up to the TOTAL VALUE in order for the Budget to be created.

8\. When done click on the UPDATE Button to complete this task.

On successful completion you will get a pop up message confirming that the operation was successful.
