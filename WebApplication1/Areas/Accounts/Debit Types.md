Debit Types

Use this sub-module to set up the various Debits Types for example; Inter account transfer of different products etc.

A Debit Type is mainly used to deduct a particular charge or charges from many individuals accounts at a go.

In this sub-module you can also tag applicable charges to that debit type.

To access this window, click :Accounts Module - > Setup - > Debit Types

The following screen will be opened:

Debit Types fig1.

How to view a debit type

1\. To view a debit Type, identify and click on that debit Type.

2\. In order to view all the:

i) Applicable charges, click on the "Applicable Charges" Button.

The applicable charges attached to this debit type is shown below

How to Create a debit Type

1\. Click on the CREATE Button, to open the following screen:

Debit type fig 3.

2\. On this Create screen, fill in all the required data in all fields:

Name - Enter the name of the Debit Type to be created

Product Code-Click on the drop down menu to select the product code.

Product - Click on the lookup icon to select the appropriate product type

3\. Applicable Charges - select by clicking on all the applicable charges.

4\. When done click on the CREATE Button to complete this task.

On successful completion you will get a pop up message confirming that the operation was successful.

How to Edit a Debit Type

1\. First Identify the Debit Type to be edited

2\. On that Debit Type that's been identified, at the far left, double click on the edit icon to open the following screen:

Debit type fig4.

3\. On this Edit screen, modify all the required data in all fields:

Name - If it's necessary you can modify / edit the name of the already existing Debit Type.

Product code-Select the appropriate product code

Product - Click on the lookup icon to select and change the product type appropriately for new / modified Credit Type .

4\. Applicable Charges - Modify if necessary by clicking (to select or unselect) on all the applicable charges. for example if its inter ac transfer debit type , the applicable charges can be "Transfer fee commission"

5\. When done click on the UPDATE Button to complete this task.

On successful completion you will get a pop up message confirming that the operation was successful.
