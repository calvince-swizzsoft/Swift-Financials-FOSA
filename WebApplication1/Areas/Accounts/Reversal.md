Reversal Journal

use this sub-module to create batches for reversals of transactions.

To access this window, click :Accounts Module - > Operations - > Batch Origination- > Reversal

The following screen will be opened:

Reversal batch fig1.

How to create a reversal

1\. Click on CREATE button the following screen will appear

Reversal batch fig 2.

Describe the type of reversal as above then click on the CREATE button.

To create a reversal batch, click on the edit icon against the correct reversal remarks.

The Batch # and remarks relating to that particular remark will be populated in their respective fields as shown below.

Reversal journal fig 3.

To add journals to be reversed to the selected remarks :

Click on Lookup Target journals look up icon(circled in black above) to open the journal lookup dialog box then select the specific type of transaction to be added to the reversal batch.

To remove any erroneous transactions/ transactions that were selected but are not to be reversed, select the transaction then click on the remove button to remove the transaction from the reversal batch.

The above steps can be used to add or remove more transactions from the reversal batch.

Reversal Journal fig 4.

From the above screen, Select which type of transaction you want to reverse from the drop down options menu.

Ensure that dates are within the appropriate range then click on the refresh button to reload data onto the screen.

Select the transactions to be reversed by ticking the check boxes against the transaction(s).

If its more than one transaction you can use Toggle selection (shown below);

Reversal Journal fig 5.

to select all the transactions on the screen, as displayed below.

Reversal Journal fig 6

Click on UPDATE button to reverse the transactions.

On successful completion you will get a pop up message confirming that the operation was successful.
