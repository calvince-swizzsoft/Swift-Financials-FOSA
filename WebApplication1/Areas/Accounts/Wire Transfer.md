Wire Transfer

Use this sub-module to create electronic funds transfer batch.

This is a transfer from a customer's primary Account to another Institution's account.

To access this window, click :Accounts Module - > Operations - > Batch Authorizations - > Wire Transfer.

The following screen will be opened:

Wire Transfer Fig1

How to Create an Electronic Funds Transfer

1\. From the figure electronic funds transfer Batch fig1. Enter all the relevant details in all the fields as follows:

Wire Transfer Fig 2.

Batch Type - Select the correct batch type to be carried out from the drop down list as shown:

Total Value - Enter the total amount to be transfered.

Wire Transfer Type - Click on the wire transfer type look up icon to open the wire transfer type look up dialog box and select the correct wire transfer type to be carried out.

Priority - Select the priority of the wire transfer from the drop down list as shown: .

Reference - Enter the appropriate reference text / number for that particular Electronic fund transfer.

2\. When done click on the CREATE Button to complete this task.

On successful completion you will get a pop up message confirming that the operation was successful.
