Use this sub-module to view all system transactions for a particular selected period.

You can use the "search field" to search for a particular system transaction journal.

Template-Based Reports

Use this sub-module to view and export the Templates that are Based on Reports e.g the SASSRA reports.

You can Export these reports to the Original Excel Files to the Template Excel files that need data to be written onto then saving them on the computer. This is faster and easier since the Excel reports will now be generated easily and faster.

This sub-module can also be used to set update/create report templates. These templates will be used to generate any required report with ease and fast.

For example to create a SASRA Template report you need to have/use the SASRA's Excel templates as a reference.

How to create a report template

1\. To create a report template, click on the CREATE Button. The following screen will be opened:

On this screen:

Parent Template- When creating a first time parent Header Entry, leave this field blank.

How To Export Data To A Report Template.

To access this window, click :Accounts Module - > Operations - > Transaction Journal - > Template-Based Reports.

The following screen will be opened:

Template-Based Reports fig1.

How to select & Export a Report

1\. Select the "Report Template" by clicking on the Lookup icon to open a "Report Template Lookup" dialog box. Select appropriately the Report Template you want to Export.

2\. Select the Posting Period by clicking on the lookup icon to open a "Posting Period Lookup" dialog box. Select the appropriate Posting Period.

3\. Select the correct "Reporting-As-At" date by clicking on the Calendar Icon. Navigate through the calendar and select the correct Date.

4\. Click on the REFRESH Button to load data onto the screen.

5\. When satisfied, click on the EXPORT Button.The following "Open Dialog box" will be opened:

6\. Find / Select the Excel Template that you want to load with data. Once you find it click on the OPEN Button (that's on that Open Dialog Box.)

7\. Once the exportation process is complete, you will be prompted to SAVE the file, select the folder where you want to save the new file with data.

On successful completion you will get a pop up message confirming that the operation was successful.

Posting Period Closing.

Close Posting Period

Use this sub-module to select and close a Posting period.

To access this window, click :Accounts Module - > Operations - > Recurring Procedures - > Posting Period Closing.

The following screen will be opened:

posting period closing fig1.

To select & Close a Posting Period

1\. Click on the look up icon to open a "Posting Period Lookup" dialog box. Select the correct posting period to be closed.

2\. Created Date - the posting period's creation date will be automatically populated to this field.

3\. Start Date - the correct posting period's start date will be populated in this field.

4\. End Date - the correct posting period's end date will be populated to this field.

5\. To close the selected posting period, click on the UPDATE Button.

On successful completion you will get a pop up message confirming that the operation was successful.
