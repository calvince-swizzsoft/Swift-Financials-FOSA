Posting Periods

Use this sub-module to set up posting periods.Its the period ie. month, fiscal year etc for which the posting is allowed.

To access this window, click: Accounts Module - > Setup - > Posting Periods

How to create a posting period

1\. Click on the CREATE Button, to open the following screen:

Posting Periods

Posting Periods fig1.

2\. On this Create screen, fill in all the required data in all fields:

Name - Enter the name of the Posting Period e.g Financial Year 2018

Start Date - Enter the start date of the financial year, e.g 1/1/2018

End Date - Enter the end date of the financial year, e.g 12/31/2018

3\. When done click on the CREATE Button to complete this task.

On successful completion you will get a pop up message confirming that the operation was successful.

How to close a posting period

Use this sub-module to close a posting period.

To access this window click:

Accounts -> Operations -> Transactions Journal -> Closing Posting Periods.
